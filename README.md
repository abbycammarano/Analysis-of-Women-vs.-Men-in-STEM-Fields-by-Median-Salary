# Analysis-of-Women-vs.-Men-in-STEM-Fields-by-Median-Salary
- This Github file is a project I constructed and wrote as a final, cumulative project for my Critical Studies of AI seminar in the Spring Quarter of my freshman year at UCLA! I chose this project path because as a woman studying STEM (specifically Statistics and Data Science), I was particularly motivated to research and illustrate the inequities that exist between male and female earnings in the workplace. I wanted this project to depict that, while so much progress has been made, we still have a long way to go as a society.
